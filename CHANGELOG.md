# Changelog

Notable changes to wvez.org. Newest first.

## 2026-09-22

- Added a blog at `/blog`, written as markdown in `_posts/` and rendered by
  Jekyll, with an RSS feed at `/feed.xml`.
- Rewrote every commit message to drop assistant co-author trailers. The file
  tree did not change.
- Added a license, a security policy, a code of conduct, contributor guidance,
  issue and pull request templates, and the commit message gate.
- Deduplicated the pendant model, which had three identical copies, renamed every
  asset to lower case with hyphens, and moved images, video and pixel art under
  `assets/`.
- Rewrote the README, which described a version of the site that no longer exists.
